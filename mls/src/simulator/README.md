# MLS Roster Investment Simulator

A roster evaluation tool for front offices. Pick a club, remove players, add MLS players or new signings, and set an extra budget. The tool shows projected points, playoff and MLS Cup probability and table rank (each with an 80% range), the best way to split the extra budget, and the club's weakest position group against the league average. It is not a 2027 forecast; offseason moves are user scenarios.

Limits stated in the tool: every minute is valued alike, so star upgrades may be undervalued (the absence study suggests elite players matter somewhat more); budget means guaranteed compensation, and salary cap, DP, TAM and GAM mechanics are not modelled.

**Current version: v1.1**, with rosters from the MLS Players Association salary release of April 16, 2026. Every input is public, and the build is reproducible from this repository.

The simulator is separate, living software. It is versioned through the offseason ([`ROADMAP.md`](ROADMAP.md)); its updates never change Paper 2.

## Versions

| Version | Rosters | Notes |
|---|---|---|
| v1.0 (development, Nov 2026) | Privately compiled club-updated salary list, March–September 2026 | Retired. Historical prototype data removed from public repository due to source restrictions |
| **v1.1** (Nov 2026) | MLSPA release of April 16, 2026, via the American Soccer Analysis API | Same model as v1.0; validated against it in [`VALIDATION.md`](VALIDATION.md) |

v1.1 reproduces v1.0's model exactly (coefficients identical to 10⁻¹⁴). With v1.0's rosters held fixed, no club's projected points move by more than 0.22. The differences between the versions come from the roster source: v1.0 was missing players at three clubs, the April release does not include summer signings, and v1.1 corrects v1.0's player matching for 45 players. Details and every number are in [`VALIDATION.md`](VALIDATION.md); the thresholds were set beforehand in [`VALIDATION_PROTOCOL.md`](VALIDATION_PROTOCOL.md).

## Build

Run from the `mls/` folder. From scratch (about 10 minutes plus downloads):

```bash
python3 src/simulator/fetch_inputs.py          # ASA stadia and match xG, football-data.co.uk MLS odds
python3 src/profiles/fetch.py && python3 src/profiles/fetch_parity.py      # ASA players, teams, games, MLSPA salaries
python3 src/paper2/espn_fetch.py usa.1 2013 2014 2015 2016 2017 2018 2019 2020 2021 2022 2023 2024 2025 2026
python3 src/paper1/random_matches.py           # match table with closing odds -> out/mls_matches.pkl
python3 src/paper2/market_gd_mls.py            # market expected goal difference -> out/market_gd_mls.pkl
python3 src/paper2/espn_shots.py usa.1         # ESPN match table -> out/espn_matches_usa.1.pkl
python3 src/paper2/peer.py usa.1 MLS --ratings-only    # market-based player ratings
python3 src/paper2/project.py                  # projection model, backtest, 2027 rosters
python3 src/simulator/tool_data.py             # projections, calibrated uncertainty, schedule -> out/tool/data.json
python3 src/simulator/roster_2027.py           # roster date, comparables for signings -> out/tool/data.json
python3 src/simulator/assemble_tool.py         # src/simulator/tool_template.html + data.json -> out/tool/index.html
```

Copy `results/espn_asa_link.csv`, `results/espn_asa_players.csv` and `results/futures_backtest.json` into `out/` first. These are the ESPN ↔ ASA crosswalks and the preseason futures check; regenerating them needs steps outside this path.

`assemble_tool.py` fills every placeholder in the template from the `meta` block of `data.json`, so the page cannot disagree with its data. Its numbers are generated by the same engine that [`validation/engine.js`](validation/engine.js) runs under Node.

## Data

All inputs are public: MLSPA salary releases and player, team and match data from American Soccer Analysis, ESPN match summaries, and closing odds from football-data.co.uk. See [`data/README.md`](../../data/README.md).

## How the model is framed

The projection model is calibrated against preseason market expectations and explains where the two disagree: against the 2025 and 2026 preseason futures, model and market correlate 0.81 and 0.80, and on the 12 largest divergences the model was closer in 5 and the market in 7. Signings are valued from comparable past arrivals by salary band and age group.
